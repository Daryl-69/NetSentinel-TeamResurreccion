How the cascade works

a small model on every window, the big one only where it matters
1 · Commissioning
The Inspector (205,546 parameters, graph + attention) learns each host's normal from the site's own traffic, unsupervised. Its alert threshold is the 99th percentile of its own error.
→
2 · Distillation
The Sentry (14,992 parameters, GRU) learns the Inspector's encoder, not its verdict: 13.7× smaller.
→
3 · Steady state
The Sentry alone scores every host-window on CPU, from categories of service (code repositories, messaging APIs, cloud storage …), never payloads.
→
4 · Escalation
The top 5% by Sentry score go back to the Inspector, which re-runs on those host-days only and returns the verdict.

What it does not claim

            
    
              
  • It is not wired into the live sensor. The Inspector needs a commissioning window of days on the site's own traffic, which this sensor has not had.
    • 
              
  • 96.9% is the share of what the Inspector would have flagged that reaches it at a 5% budget, not a detection rate.
    • 
              
  • On real data (LANL) the Inspector's within-host AUC is 0.557 ± 0.013, near chance: the weakest number, stated here on purpose.
    • 
              
  • A Telegram-API implant that perfectly mimics its host is not caught in a window; the claim is a bound — any real exfiltration rate is caught within a delay its own bandwidth sets.
    • 
              
  • 13.7× is a size ratio. The Sentry's speed advantage on CPU was about 8× on one shared machine.
    •

How alerts are sealed

          
    
            
  1. Receipt. Each alert gets an in-toto statement recording the evidence digest, feature digest, model digest and decision, signed with the sensor's Ed25519 key (DSSE).
    2. 
            
  2. Window. Receipts are batched into a Merkle tree; the root is appended to a hash-chained ledger.
    3. 
            
  3. Checkpoint. A signed tree head is published and anchored, so later edits to any alert are detectable.
    4. 
            
  4. Verify. Anyone with the receipt can re-check the claims and replay the model to get the same score.
